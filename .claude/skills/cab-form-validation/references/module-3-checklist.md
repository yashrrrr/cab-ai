# Module 3 — CR Form Validation Guidance

Applies to the CR text itself, regardless of type (infrastructure or
application). Source of truth — copied verbatim from the CAB Readiness
Agent brief.

| Area | Requirement |
|---|---|
| Business Justification | Clearly describe why the change is required. |
| Problem Statement | Define the existing issue or business need. |
| Proposed Solution | Explain the planned solution or change. |
| Expected Outcomes | Document expected benefits and outcomes. |
| Consumer/Stakeholder Impact | Identify affected users, systems, or stakeholders. |
| Implementation Details | Detailed implementation plan must be provided. |
| Testing Evidence | Test execution results and sign-offs must be attached. |
| Supporting Documents | All mandatory approvals, assessment reports, and design documents should be attached before submission. |
