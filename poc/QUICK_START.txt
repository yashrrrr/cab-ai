━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ DETERMINISTIC CLASSIFICATION
   → Change Type: Normal, Expedited, Emergency, Standard, No Impact
   → Impact: High, Medium, Low (based on scope, downtime)
   → Priority: Critical, High, Moderate, Low (based on service/security)
   → Risk: 1-5 scale (based on users, outage, history)

   🔒 GUARDRAIL: No LLM guessing. Rules + lookup tables only.

✅ STANDARD CHANGE AUTO-APPROVAL
   → RFC matches SCC (Standard Change Catalogue)? → Auto-approve (seconds)
   → Otherwise → Route to human approval

   🔒 GUARDRAIL: Only genuinely low-risk changes auto-approve.

✅ NO IMPACT TWO-TIER APPROVAL
   → Coordinator reviews + Manager reviews + signs off
   → Ambiguous criteria? → Escalate to CAB (don't guess)

   🔒 GUARDRAIL: Never auto-approve if uncertain.

✅ AI CAB DELIBERATION
   → 5 agents review collaboratively:
      • Infrastructure Specialist (downtime, back-out)
      • Application Specialist (tests, deployment)
      • Business Owner (justification, SLA impact)
      • Security Officer (security, VAPT)
      • Change Manager / Chair (synthesize, decide)

   → Chair makes final call: Approve / Reject / Conditional

   🔒 GUARDRAIL: AI is advisory. Human decides. Human is accountable.

"I can't see the frontend"
  → Check: http://localhost:3000 is loading
  → If blank: Check browser console (F12) for errors
  → Backend URL wrong? Edit frontend/.env

"I can't reach the API"
  → Check: http://localhost:8000/health returns {"status":"ok"}
  → If error: Backend not running. Run 'python main.py'

"CAB session is slow"
  → Normal: Claude API calls take 30–60 seconds
  → Check: Backend logs for errors
  → Retry: Click button again after 1 minute

"No sample RFCs visible"
  → Run: python db_init.py (in backend/)
  → Then: Restart backend and refresh frontend
